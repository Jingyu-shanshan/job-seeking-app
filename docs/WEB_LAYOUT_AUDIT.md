## 已修复问题

**[P2] Sources 的长来源名称把 “Use” 挤成竖排。**

位置：`apps/web/src/app/sources/catalog-entry.ts` 的来源启用复选框标签。

标签采用共享 flex 排列，但 `Use` 文本和加粗的来源名称是独立项目。来源名称较长时，前面的短词被挤成逐字换行，影响阅读和复选框与说明文字的对齐。普通来源名称下不容易发现，单测和页面总宽度检查也不会报错。

修复：把 `Use` 和来源名称包装为一个文本项目，继续使用既有换行规则和复选框样式。没有新增 CSS、依赖或业务逻辑。修复前在 320px 测得 `Use` 文本范围高 66px、行高 24px；修复后在 320/360/900/1440px 均为 18px，且页面不横向溢出。手机和桌面截图已目检。

`scripts/ui-acceptance.mjs` 新增长来源名称的浏览器回归：使用只拦截显示数据的 198 字符来源名称，测量 `Use` 的真实文字范围，防止只检查页面总宽度而漏掉此类局部排布问题。
